# Rafi Personal Link Hub

Personal link hub statis dengan gaya creative-agency editorial, dibuat menggunakan HTML, CSS, dan JavaScript murni.

## Isi utama
- Foto profil pribadi sebagai visual hero.
- Favicon logo R.
- Tautan Portfolio, GitHub, LinkedIn, Instagram, NusaMind AI, dan Private Portfolio.
- Layout responsif dan kompatibel dengan GitHub Pages.
- Tidak memerlukan backend, database, package manager, atau proses build.

## Deploy GitHub Pages
Upload semua isi folder ini ke repository GitHub. Di `Settings > Pages`, pilih branch `main` dan folder `/ (root)`.
