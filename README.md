# Rafi Personal Link Hub

Website personal link hub statis untuk GitHub Pages.

## Perubahan terbaru
- Foto profil utama menggunakan foto pribadi.
- Favicon menggunakan logo huruf R.
- Warna website disesuaikan mengikuti nuansa logo biru, putih, merah, dan kuning.
- Link Instagram diperbarui.
- Link Academic Organizer dihapus dari daftar tautan.

## Deploy GitHub Pages
Upload semua isi folder ini ke repository GitHub, lalu aktifkan Pages dari branch `main` dan folder `/ (root)`.
