# Security Policy

## Supported Version

Versi yang didukung adalah branch `main` dan deployment GitHub Pages terbaru.

## Reporting a Vulnerability

Jangan membuka public issue untuk kerentanan yang belum diperbaiki. Gunakan **Security → Advisories → Report a vulnerability** pada repository ini agar detail dapat ditinjau secara privat.

Jika private vulnerability reporting belum tersedia, hubungi pemilik repository melalui [LinkedIn](https://www.linkedin.com/in/rafipriyo) tanpa menyertakan bukti eksploitasi atau data sensitif di ruang publik.

Sertakan deskripsi masalah, langkah reproduksi yang aman, dampak, dan saran perbaikan bila tersedia. Jangan melakukan pengujian yang merusak, mengubah data, atau mengganggu layanan.
